The Invitational's trigger fires on 30 October and every later day, so the shots use Tuesday 22 September. Rejected: a November date. (Claude's call.)

Rejected: the starter deck, which holds four cats. (Claude's call.)

Bucket's deck holds Good News, Everybody and Lovelace's holds Party Time. Excellent., so neither is played against; they appear only as portraits. Rejected: answering None for both, which gives 9+ but risks a challenge in review. Brent's decision. (Claude's reading.)
