## What I worked on

Process, not game code. The brent-ops plugin (`/next`, `/route`, `/daily`,
`/log`, `/verify`, `/weekly`) now reads one `## brent-ops` block at the end
of `CLAUDE.md`, and this directory replaces the `## Current state` section of
`CLAUDE.md` as the running log.

## What got done

- **`docs/logs/` exists.** `README.md` holds the template and rules.
- **The history moved out of `CLAUDE.md`.** Its `## Current state` section
  (2,600 lines of per-step notes, 0.1 through the bug-fix pass) became
  `docs/logs/2026-09-10.md`, `2026-09-11.md`, `2026-09-12.md` and
  `2026-09-15.md`, dated by the commits, text verbatim, one `## Also this
  session` block per step. The 300-line gotcha list stayed in `CLAUDE.md` as
  its own `## Gotchas` section. `CLAUDE.md` went from 3,083 lines (195 KB) to
  498 lines (29 KB). Checked line by line: every non-blank line of the old
  section is in a log file or in `## Gotchas`.
- **The `## brent-ops` block is declared** at the end of `CLAUDE.md`:
  `logs.dir: docs/logs`, `reviews.mode: "off"`, plan ids
  `<phase>.<step>[letter]` and `PT-n`, commits through `ss-ship` to `main`,
  no dispatch tool.
- **Plan §2 rule 4 now points here.** "Every session ends by updating
  `CLAUDE.md`" became "every session ends with a `docs/logs/` entry".

## Decisions made

- **No build reviews for this project** (Brent, 2026-09-16). The repo takes
  code commits only from Brent, straight to `main`, so the review and pull
  request machinery Wildlife Crossing uses stays off here.

  2026-09-16). `## Current state` had grown to about 2,900 lines, which is
  the opposite of what plan §2 rule 4 wanted from a handoff doc.
